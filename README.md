# 📊 Data Analysis Specialisation 2019 - 2020 

### 📝 Description 
This repository contains my study projects completed during the **Data Analysis Specialisation** by [TripleTen](https://tripleten.com/data-analytics/).

The programme covered the fundamentals of data analysis, including data preprocessing, exploratory data analysis, statistical analysis, SQL, business analytics, data visualization, and forecasting. The projects in this repository were created for educational purposes and helped me practice working with real datasets and analytical tools. **⏳ Duration:** 8 months
